# Рассказчик у камина

Мультяшный рассказчик хоррор-историй для роликов на YouTube. Сидит в кресле, открывает рот под загруженную озвучку или голос в микрофон.

## Что умеет

- 6 локаций: комната у камина, детская, подвал, ночной лес, больница, чердак. Переключатель в панели под сценой.
- У каждой локации свои звуки (скрип досок, позвякивание колокольчиков, костёр и лягушки, мерцающая лампа и другие). Все звуки синтезируются в браузере, файлов не нужно.
- Рот двигается по громкости озвучки. Чувствительность настраивается.
- Кнопка «Записать ролик» сохраняет видео 1920×1080 с озвучкой и звуками локации.
- «Режим съёмки» оставляет на экране только сцену.

## Структура

```
src/index.html        приложение целиком (разметка, стили, скрипт)
scripts/build.mjs     сборка: src/index.html -> dist/index.html
scripts/serve.mjs     локальный сервер для проверки сборки
.github/workflows/    автосборка и публикация на GitHub Pages
```

## Сборка и запуск

Зависимостей нет, нужен только Node.js 18 или новее.

```
npm run build   # создаёт dist/index.html
npm start       # http://localhost:8080
```

## Публикация на телефон

После пуша в `main` GitHub Actions собирает проект и публикует его на GitHub Pages. Один раз включите Pages: Settings → Pages → Source: GitHub Actions. Адрес будет вида `https://<логин>.github.io/horror/`.

Микрофон работает только на странице, открытой по https (GitHub Pages подходит).
